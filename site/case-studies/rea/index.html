Case study

What “Reverse Engineer Anything” does to your machine

REA is a popular MCP server that lets AI agents drive decompilers, browsers and live programs. Before connecting a tool like that to an agent, we wanted to know what it is and what it can do. Clearbox read commit a95795c in 15 seconds without running any of it.

Findings

Four things worth knowing before you install it

Each comes from a report linked below, and each line of evidence links to that line in REA's source on GitHub.

Pattern

It launches programs and drives terminals

106 production files can start other processes and 5 drive an interactive terminal through node-pty. That is how REA runs Ghidra, Hopper and target programs. It also means anything it runs gets your user's permissions; REA's own security policy says it is not a sandbox.

Evidence
159 siteschild_process: spawn, execFile, fork
ProcessHarness.ts:265const { spawn } = await import("@lydell/node-pty");

Pattern

It can install software as root

The Linux Hopper installer calls apt-get, dnf or pacman and escalates with pkexec. REA documents this and asks first. Clearbox found it in one file, with line numbers, without installing anything.

Evidence
LinuxHopper.ts:337const executable = isRoot ? command[0] : "pkexec";
LinuxHopper.ts:329["apt-get", "install", "-y", archive, ...runtimeDependencies]
Heuristic

Its setup edits your AI agents' configuration

Tracing “setup agent client configuration” finds 10 files reached from the rea command. They read and write other applications' config files, consult 32 environment variables, and are covered by 36 test files. The report includes a 10-step plan to rebuild the feature.

Architecture

A domain core with many adapters

The overview groups REA's 42 areas and shows which import which. The most-imported files are small domain types: result.ts (231 importers), jsonValue.ts (215) and the error core (202). Changing one of those ripples through most of the codebase.

  • 42 areas; largest are src/domain (102K lines) and src/application (54K)
  • 82 third-party packages actually imported
  • 284 imports point at build output and were mapped back to source
